  Example Project
  Create a project with these values on the workspace page:

  - Project title: Q3 Product Launch Landing Page
  - Content type: Landing page
  - Audience: Marketing managers
  - Tone: Confident and clear
  - Goal: Demo bookings

  Brief / source content:

We are launching a new AI writing workspace for small content teams. The product helps writers move from rough notes topolished copy in one connected
workflow. It includes content analysis, draft generation, guided improvement tools, revision chat, and a final pass forpolished output. Our target
audience is marketing managers at small SaaS companies who need to publish landing pages, launch emails, and campaign copyfaster without losing brand
clarity. The main value is speed, consistency, and fewer revision loops. The primary call to action should encouragevisitors to book a demo.

  Steps To Follow

  1. Open / and create the project using the values above.
  2. Open Analyze Content and click Analyze.
  3. Open Draft Writer and generate a first draft.
  4. Open Content Tools and improve the draft for the selected audience and goal.
  5. Open Revision Chat and ask for refinements.
  6. Open Final Pass and generate the final version.
  7. Return to the workspace and confirm the project still shows its saved progress.

  Text To Input On Each Page

  Analyze Content:
  Use the same brief above.

  Draft Writer:

  Write a landing page hero section and short supporting copy for this product launch. Focus on helping small content teams move from rough notes to
  polished copy faster. Make it clear, modern, and conversion-focused. End with a call to action that encourages visitors to book a demo.

  Content Tools:

  Improve this landing page copy for marketing managers at small SaaS companies. Make the value clearer, highlight speed and consistency, and strengthen
  the call to action for demo bookings.

  Revision Chat first message:

  Make this version sharper and more persuasive without sounding exaggerated. Keep it clear and suitable for a SaaS landing page.

  Revision Chat second message:

  Now shorten it slightly and make the headline stronger for busy marketing managers.

  Final Pass:

  Create the final landing page hero, subheading, and short supporting paragraph for this product. Keep it polished, concise, and ready for a live SaaS
  website. End with a strong demo booking call to action.

  What Good Output Should Look Like
  By the end, you should have:

  - a suggested title, category, summary, and tags from analysis
  - a first landing page draft
  - an improved version shaped for marketing managers
  - a refined version from chat
  - a final polished landing page version saved in the project
